## 📊 Sobre o Projeto
O **Educa Livre** é uma plataforma inovadora de ranking educacional que classifica escolas com base em múltiplos critérios personalizáveis. Os usuários podem buscar instituições de ensino de acordo com suas preferências específicas.

### 🎯 Funcionalidades Principais
- **🔍 Buscas Personalizadas** por nota, distância e selos de qualidade
- **🏅 Sistema de Selos** que reconhecem iniciativas especiais:
  - Selo de Igualdade Salarial
  - Selo de Iniciativa Científica
  - E muitos outros!
- **📈 Ranking Dinâmico** baseado em múltiplos critérios
- **📍 Localização Geográfica** para busca por proximidade

## 🛠️ Stack Tecnológica
- **Backend:** ASP.NET MVC
- **Banco de Dados:** MySQL (XAMPP/MariaDB)
- **Frontend:** HTML, CSS, JavaScript
- **Futuro:** Animações avançadas em JavaScript para Login e Menu
